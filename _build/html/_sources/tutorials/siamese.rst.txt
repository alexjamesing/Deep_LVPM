Siamese CIFAR-10 Tutorial
=========================

The Siamese tutorial demonstrates how to configure :class:`deep_lvpm.models.StructuralModel` in ``is_siamese`` mode to learn contrastive embeddings.  It uses CIFAR‑10, applies strong stochastic augmentations to create correlated views, and then evaluates the learned representation with a linear probe.

Run the full pipeline via:

.. code-block:: bash

   python -m deep_lvpm.tutorial.tutorial_siamese_tf

or import :mod:`deep_lvpm.tutorial.tutorial_siamese_tf` into a notebook to customise batch size, embedding dimensionality, or training duration.

Workflow overview
-----------------

1. **Data loading and preprocessing** – load CIFAR‑10, normalise to [0, 1], and create train/validation splits.
2. **Augmentation** – build a Keras Sequential pipeline with random cropping, resizing, flips, and occasional grayscale conversion to form positive pairs.
3. **Siamese StructuralModel** – instantiate a single convolutional encoder and pass it twice to :class:`StructuralModel` with ``is_siamese=True`` and ``orthogonalization="zca"`` so that both branches share weights.
4. **Training** – fit the model on a ``tf.data`` pipeline of paired augmentations; monitor validation metrics including redundancy to ensure factors stay diverse.
5. **Linear evaluation** – truncate the encoder, export embeddings, and train a softmax classifier to quantify downstream utility.

Code highlights
---------------

.. code-block:: python

   import keras
   from keras import layers
   import tensorflow as tf
   from deep_lvpm.models.StructuralModel import StructuralModel

   augment = keras.Sequential(
       [
           layers.RandomCrop(24, 24),
           layers.Resizing(32, 32),
           layers.RandomFlip("horizontal"),
           layers.Lambda(
               lambda x: tf.where(
                   tf.random.uniform([tf.shape(x)[0], 1, 1, 1]) < 0.2,
                   tf.tile(tf.image.rgb_to_grayscale(x), [1, 1, 1, 3]),
                   x,
               )
           ),
       ],
       name="cifar_augment",
   )

   encoder = keras.Sequential(
       [
           keras.Input(shape=(32, 32, 3), name="cifar_in"),
           layers.Conv2D(64, 3, padding="same", activation="relu"),
           layers.MaxPooling2D(2),
           layers.Conv2D(128, 3, padding="same", activation="relu"),
           layers.MaxPooling2D(2),
           layers.Conv2D(256, 3, padding="same", activation="relu"),
           layers.GlobalAveragePooling2D(),
           layers.Dense(512),
           layers.BatchNormalization(),
           layers.Dense(512),
           layers.BatchNormalization(),
           layers.ReLU(),
           layers.Dense(512),
           layers.BatchNormalization(),
       ],
       name="cifar_encoder",
   )

   adjacency = tf.constant([[0, 1], [1, 0]], dtype="float32")

   struct_model = StructuralModel(
       Path=adjacency,
       model_list=[encoder, encoder],
       regularizer_list=[None, None],
       tot_num=len(x_train),
       ndims=512,
       orthogonalization="zca",
       train_DLV=True,
       is_siamese=True,
       diag_offset=1e-4,
   )
