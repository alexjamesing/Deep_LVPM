MNIST Tutorial (Keras 3 / TensorFlow)
====================================

This walkthrough demonstrates how to connect greyscale MNIST images with dummy-coded labels using the :class:`deep_lvpm.models.StructuralModel`.  The implementation uses **Keras 3** with the **TensorFlow** backend, but the high-level logic is identical for other backends supported by Keras 3.

At the end of training we inspect the metrics reported by ``model.evaluate`` — total loss, the mean cross-view correlation, reconstruction error, and the **redundancy** score that summarises correlation between discovered DLVPM factors.  We also visualise the latent space with t‑SNE.

Prerequisites
-------------

Install ``deep_lvpm`` with a TensorFlow backend as described on the :doc:`installation` page, then run the helper:

.. code-block:: bash

   python -m deep_lvpm.tutorial.tutorial_mnist_tf

The dedicated script executes the steps below end-to-end; the following snippets highlight the main components.

1. Load and prepare the data
----------------------------

.. code-block:: python

   import numpy as np
   import keras

   num_classes = 10

   (x_train, y_train_cat), (x_test, y_test_cat) = keras.datasets.mnist.load_data()
   x_train = (x_train.astype("float32") / 255.0)[..., None]
   x_test  = (x_test.astype("float32") / 255.0)[..., None]

   y_train = keras.utils.to_categorical(y_train_cat, num_classes)
   y_test  = keras.utils.to_categorical(y_test_cat, num_classes)

   data_train = [x_train, y_train]
   data_test  = [x_test,  y_test]

2. Define the measurement models
--------------------------------

Each view requires a Keras model.  Images are encoded with a small CNN, while labels pass through an identity mapping.

.. code-block:: python

   from keras import layers, regularizers

   image_encoder = keras.Sequential(
       [
           keras.Input(shape=(28, 28, 1), name="mnist_image_in"),
           layers.Conv2D(32, (3, 3), activation="relu",
                         kernel_regularizer=regularizers.l1_l2(1e-5, 1e-5)),
           layers.MaxPooling2D((2, 2)),
           layers.Conv2D(64, (3, 3), activation="relu",
                         kernel_regularizer=regularizers.l1_l2(1e-5, 1e-5)),
           layers.MaxPooling2D((2, 2)),
           layers.Flatten(),
           layers.Dense(128, activation="relu"),
           layers.Dropout(0.5),
       ],
       name="mnist_image_encoder",
   )

   labels_input = keras.Input(shape=(10,), name="mnist_label_in")
   labels_output = layers.Activation("linear", name="mnist_label_id")(labels_input)
   label_encoder = keras.Model(labels_input, labels_output, name="mnist_label_encoder")

3. Configure the structural model
---------------------------------

.. code-block:: python

   import numpy as np
   from deep_lvpm.models.StructuralModel import StructuralModel
   from keras.optimizers import Adam

   adjacency = np.array([[0, 1], [1, 0]], dtype="float32")

   struct_model = StructuralModel(
       Path=adjacency,
       model_list=[image_encoder, label_encoder],
       regularizer_list=[None, None],
       tot_num=x_train.shape[0],
       ndims=9,
       orthogonalization="Moore-Penrose",
       momentum=0.95,
       epsilon=1e-4,
       train_DLV=False,
   )

   struct_model.compile(optimizer=[Adam(1e-4), Adam(1e-4)])

4. Train, evaluate, and inspect latent variables
------------------------------------------------

.. code-block:: python

   history = struct_model.fit(
       data_train,
       batch_size=256,
       epochs=20,
       validation_split=0.1,
       verbose=True,
   )

   metrics = struct_model.evaluate(data_test, verbose=False)
   print({k: float(v) for k, v in metrics.items()})

   latent = struct_model.predict(data_test, verbose=False)
   image_latent = struct_model.model_list[0].predict(data_test[0], verbose=False)

   from sklearn.manifold import TSNE

   tsne = TSNE(n_components=2, random_state=42)
   embedding = tsne.fit_transform(image_latent[:200])

The standalone script stores the training history and prints evaluation metrics (including redundancy) so you can monitor both cross-view alignment and within-view redundancy without additional boilerplate.
